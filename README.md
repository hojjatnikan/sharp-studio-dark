# Sharp Studio Dark

A polished **Visual Studio-like dark theme and icon pack** for JetBrains Rider.

## Overview

Sharp Studio Dark is designed to make Rider feel closer to modern Visual Studio aesthetics, including:

- Dark UI palette inspired by Visual Studio
- Carefully tuned editor colors
- Custom icon set for a cohesive coding experience
- Focus on readability and reduced visual noise

## Features

- 🎨 Visual Studio-inspired dark appearance
- 🧩 Integrated UI + editor styling
- 🗂️ Consistent iconography across project tree and actions
- ⚡ Built for day-to-day development comfort

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/hojjatnikan/sharp-studio-dark.git
   ```
2. Build/package the plugin according to project scripts.
3. Install in Rider and activate the theme from Appearance settings.

## Usage

After installation:

- Set theme to **Sharp Studio Dark** (or provided VS-like dark theme)
- Select the matching editor color scheme
- Restart Rider if needed
