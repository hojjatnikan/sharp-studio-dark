You already know these colours. Sharp Studio Dark gives JetBrains Rider the window chrome, the editor palette and the icons of Visual Studio 2026 — for C# developers who live in Visual Studio but want their Rider to feel like home.

Every colour was sampled from a real Visual Studio window, pixel by pixel, instead of guessed from memory — so the two IDEs sit side by side and your eyes never have to readjust.

🎨 What you get

Visual Studio 2026 dark chrome Title bar #1C1C1C, menu and toolbar strip #262626, tool windows #282828, editor #1E1E1E, status bar #141414 — and the flat grey selection with the blue active-tab underline that Visual Studio uses instead of a coloured highlight.
An editor scheme named Sharp Studio Dark The exact syntax palette you already read every day — keywords, strings, numbers, types, methods, comments, caret and selection.
210 icons · 719 platform paths Green C# files, grey window tiles with the blue globe for web projects and the purple C# mark for class libraries and solutions, golden folders, photo-frame images, flat monochrome toolbars.
Nothing but resources A theme descriptor, one colour scheme and SVG files. No code runs in your IDE — no background services, no telemetry, nothing to trust beyond what you can see.

Install in three steps

  1. Install Sharp Studio Dark and restart Rider.
  2. Open Settings | Appearance & Behavior | Appearance.
  3. Set Theme → Sharp Studio Dark and Editor color scheme → Sharp Studio Dark. Done.

Compatibility: Rider 2025.1 and newer. Works out of the box — 100% resource plugin, no setup, no configuration files.

Good to know

  • Other icon packs win. VSCode Icons, Catppuccin Icons and friends replace file icons for every theme. Disable them if you want the Visual Studio icons to show.
  • Dark only, on purpose. The pack is drawn for dark backgrounds; a light variant may come later.
  • Dialogs stay stock. Message boxes and buttons keep Rider's own styling so they stay readable — only theme surfaces are recoloured.
  • After an update Rider may reset the selected theme; just re-select Sharp Studio Dark in Settings | Appearance.
